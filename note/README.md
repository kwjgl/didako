# note/ · 디다코 노트 데모 앱

## 두 모드

- `config.js`의 `HUB_URL`이 비어 있거나 주소에 `?demo`가 있으면 기존 데모예요. 설정 파일이 없어도 데모로 열려요. 아래 데모 설명은 이 모드의 이야기예요.
- `HUB_URL`이 있고 `?demo`가 없으면 실제 앱이에요. 카카오 로그인 → 교회 코드 → 교회 서버로 들어가요. 데모 톱니와 시안 안내는 보이지 않고 기기의 오늘을 써요. 서비스워커도 이 모드에서만 등록해요.
- 설정 세 값은 `HUB_URL`(코이데 기본 서버 웹 앱 주소), `KAKAO_REST_KEY`(공개 REST API 키), `REDIRECT_URI`(카카오에 등록한 노트 주소)예요. Client Secret은 넣지 않아요. **gbs에서는 세 값을 늘 비워 두고, 실제 값은 공개 저장소 didako의 `note/config.js`에만 넣어요**(`docs/setup.md`).
- 기억 자리는 `didako-note-notes`·`didako-note-badges`·`didako-note-session`·`didako-note-demo`를 그대로 써서 지도가 읽어요. `didako-note-owner`는 지금 주인 uid, `didako-note-stash.<uid>`는 다른 주인의 사본이에요. `didako-note-gone`은 지운 표시, `didako-note-lock`은 이 기기의 무작위 열쇠, `didako-note-vault`는 `{ on, salt, rev, last, pend, rec }`예요. 로그인은 `didako-hub-token`·`didako-token`·`didako-uid`, 교회는 `didako-church-url`·`didako-church-name`·`didako-church-kind`에 둬요. 로그아웃해도 기기의 기록은 남아요.
- 동기화를 켜면 무작위 열쇠로 기록을 AES-GCM 암호화해 맡겨요. 열쇠는 비밀 문구와 복구용 낱말로 각각 잠그고(PBKDF2-SHA256, 250,000번), 문구와 낱말은 저장하지 않아요. 이름도 잠긴 덩어리 안에만 보내요.
- 맞출 때 질문·발견은 id별 최신 touched(같으면 이 기기), 이번 주 생각은 최신 at, 탐구는 질문별 최신 touched를 받아요. 현재 탐구는 이 기기 순서 뒤에 상대 것을 겹침 없이 세 개까지 두고, 배지·처음 온 날은 이른 날, 본 배지와 지운 표시는 합쳐요. 이름은 이 기기에 없을 때만 받아요. 지운 항목을 뺀 뒤 다시 정리해요. 서버의 판이 바뀌면 세 번까지 다시 맞춰요. 앱을 열거나 다시 보일 때, 글·배지 저장 후 4초 쉬었다가 맞춰요.
- `words-ko.js`는 [코이데 원본](https://raw.githubusercontent.com/kwjgl/koide/main/app/words-ko.js)을 그대로 복사했어요(BIP-39 한국어 2048개, MIT 안내 포함). 실제 모드에서만 쓰고, 데모는 기존 예시 낱말을 써요.
- 실제 모드에서 카카오 로그인 뒤 서버 확인 중에는 시작 버튼을 잠그고 "카카오 로그인을 확인하고 있어요…"를 보여 줘요. 앱이 다시 보일 때 날짜가 바뀌었으면 오늘 화면을 새로 그려요(시트가 열렸거나 쓰는 중이면 다음 화면 이동 때). 아이폰에서 글자 칸을 눌러도 저절로 확대되지 않게 viewport에 maximum-scale=1을 둬요.
- 홈 화면 아이콘은 먹색 바탕의 세 겹 책갈피예요(원본 icons/icon.svg). 코이데·GBS 앱의 초록 아이콘과 나란히 두어도 구별되게 했어요. 앱 안의 색은 초록 그대로예요. 아이폰은 홈 화면에 추가할 때 아이콘을 한 번만 가져가니, 바뀐 아이콘을 보려면 홈 화면에서 지우고 다시 추가해요.
- 실제 모드에서 더보기 맨 위에 들어와 있는 교회 이름을 보여 줘요. [이 질문으로 하나님께 기도하기]는 질문 글을 복사하고 코이데 기도 노트(https://koide.koinobia.com/app/note.html)를 새 창으로 열어요(코이데에 미리 채우는 기능은 아직 없어요). 그림(img/)은 서비스워커가 남겨 둔 사본을 먼저 보여 줘요.
- 내 기록의 질문과 발견은 휴지통 아이콘으로 지워요. 확인 창에 지워지는 것을 나열해요. 질문을 지우면 탐구 노트도 지워지고, 붙어 있던 발견은 '발견만'으로, 이 질문에서 나온 질문은 그대로 남아요. 동기화를 켰다면 지운 표시가 다른 기기에도 가요. 질문 다듬기의 문장 틀을 누르면 틀 안의 ___가 선택된 채로 들어가 바로 고쳐 쓸 수 있어요.
- 탐구하기는 내가 탐구하는 질문을 먼저, 이번 주의 질문을 그 아래 카드로 보여 줘요(장절은 작은 한 줄, 그림은 잘리지 않게 카드 폭 가득). 이번 주의 질문을 마무리까지 펴면 wk에 done(시각)을 남겨 카드에 "✓ 다 펴 봤어요"를 붙이고, 내 기록 오른쪽 위 달력 아이콘의 "펴 본 이번 주의 질문" 페이지에서 해마다 넘겨 봐요. 숫자는 쓰지 않아요(철학 ③).
- 아이폰 홈 화면 앱은 다른 웹앱을 링크로 열 수 없어서, 기도하기를 누르면 질문만 복사하고 기도 노트를 직접 열어 붙여 넣도록 알려 줘요. 연월 고르기는 질문 다듬기와 남기기 모두 줄을 누르면 바로 떠요.
- 화면이 바뀔 때 코이데와 같은 움직임으로 넘어가요(오른쪽 탭은 오른쪽에서, 왼쪽 탭은 왼쪽에서, 같은 탭 안은 살며시). 움직임 줄이기를 켠 기기에서는 움직이지 않아요. 아래에 버튼 막대가 붙는 화면(탐구 노트, 이번 주의 질문)도 움직이지 않고 바로 보여요.
- 내 기록의 걸러 보기는 전체 · 탐구 중 · 질문만 · 질문과 발견 · 발견만이에요. 탐구 중인 질문은 질문만·질문과 발견에 다시 나오지 않고, 전체에서는 맨 앞에 와요. 탐구 중인 쪽지에는 테마색 나침반과 오른쪽 위 책갈피 리본, 진행 점이 붙고, 예전에 탐구한 쪽지에는 흐린 나침반만 붙어요.

디다코 노트(개인용)를 **눌러 볼 수 있게** 만든 데모예요. GBS 앱(`app/`)과 따로 있고, `app/`은 건드리지 않아요.

- **설정이 비어 있으면 서버가 없어요.** 쓴 것은 이 브라우저(localStorage)에만 남아요. 카카오 로그인, 교회 코드, 동기화의 잠금은 모두 흉내만 내요(실제 잠금은 2단계). 남긴 질문과 발견도 데모라 잠그지 않고 이 브라우저에만 두어요.
- **이번에 되는 것(① 뼈대·첫 접속·오늘의 질문·더보기, ② + 남기기·내 기록, ③-1 탐구하기, ③-2 자유롭게 쓰기와 내보내기):** 첫 접속, 오늘의 질문(409개, 교회력 계산, AI 초안), 지난 질문(한 달씩 넘겨 보기, 눌러 펴기), 더보기(화면 설정, 소개, 사용법, 의견 보내기, 동기화 데모). **+ 남기기**에서 질문·발견을 적고(장절 알아듣기, 예전에 생긴 것 연·월, 오늘의 쪽지, 오늘의 질문에서 품기), 적고 나면 질문을 남겼어요 카드와 발견 짝 찾기가 떠요. **내 기록**은 쪽지 벽(칩 네 개), 질문 펴기(말씀을 열며 없이 바로 펴져요. 지나온 길, 더 품을게요, 짝 풀기·옮기기), 짝 찾기, 직접 고르기, 검색이에요. 태블릿·PC 넓은 화면(1000px 이상)도 있어요(옆 칸과 내용이 위쪽 메뉴 폭으로 묶여 가운데에 놓여요. 남기기 오른쪽 칸, 벽 4열과 오른쪽 패널). **탐구하기(③-1)**는 첫 화면(이번 주의 질문, 내가 탐구하는 질문 하나, 지난 탐구), 이번 주의 질문(말씀을 열며 뒤 내 생각 → 함께 볼 말씀 → 교회가 고백해 온 것 → 마무리), "어떻게 탐구할까요?", 단계별로 쓰기(하나씩 쓰기 ①~⑤와 모아 보기)가 돼요. 쓰는 칸의 `? ` 줄은 새 질문으로, `! ` 줄은 지나온 길의 "알게 된 것"으로 들어가고, ⑤의 [! 발견]은 그 질문을 알게 된 질문으로 만들어요. 이번 주의 질문은 52개예요(하이델베르크 요리문답 52주일 순서, 1월 첫 주일이 1주, AI 초안, 교역자 확인 전). **자유롭게 쓰기(③-2)**는 "어떻게 탐구할까요?"에서 [자유롭게 쓰기]를 고르면 빈 종이로 시작해요(서식 막대, '/' 메뉴, 표, 접는 섹션, 구분선, 줄 앞 `? `·`! ` 상자, 장절 알아듣기, 자동 저장과 [저장 ✓], 전체 화면, 화면 꺼짐 방지). ⋯ 메뉴에서 단계별로 쓰기와 자유롭게 쓰기를 오갈 수 있고, 두 방식의 글은 따로 남아요. **내보내기**(PDF · Markdown · TXT · HTML · 마크다운 복사)는 하나씩 쓰기, 모아 보기, 자유롭게 쓰기의 ⋯ 메뉴에서 해요. 말씀을 열며는 이번 주의 질문에서 [펴 보기]를 누를 때 나와요.
- **나의 배지**(`#/mine/badges`): 앱을 하나씩 써 보는 일 11개와 기념 1개. 내 기록 제목 줄 단추에서 열어요. 숫자는 없어요. 받은 날은 이 브라우저(`didako-note-badges`)에만 저장해요.
- **처음에는 내 기록이 비어 있어요.** 톱니(시안 보기 설정)의 **예시 기록 채우기**를 누르면 캔버스 보드의 지어낸 질문·발견(날짜는 누른 날 기준)으로 바뀌어요. 짝 찾기는 겹치는 낱말, 작은 비슷한 말 사전, 같은 책·가까운 장절로 점수를 내는 1단계 방식이고, 바깥으로 보내지 않아요.
- **화면 기준:** 디자인 캔버스 `prototype/mulpyo/`(첫 접속·오늘의 질문·더보기: M18~M18d, Main, M10, M1c, M8~M8i, T8, T13 / + 남기기: M13, M2, M4, M5, M5b, M5c, M22, T9, T10 / 내 기록: M20, M20b, M20c, M25, M12, M6, M11, M19, M21, M26, M27, M27b, M24, T11, T12, P1 / 탐구하기: M7, M7a, M7b, M7b2, M7c, M30, M9s, M9a, M9b, M9b0, M9b0a, M9, M9c, M90, M90a, M9d, M15, M9h, M29, T1, T2, T2a, T4, T5, T6 / 자유롭게 쓰기·내보내기: M9f, M9g, M14, M14b, M23, M17, T7, T3)와 `docs/prd.md`, `Intent.md`예요.
- **하단 탭 아이콘:** 오늘의 질문 시계, 탐구하기 나침반, 남기기 +, 내 기록 겹친 쪽지 두 장, 더보기 점 셋이에요. 탐구하기 첫 화면의 이번 주의 질문 카드에는 제○주일·주제와 함께 볼 말씀 칩이 있어요.
- **파일:** `index.html`(앱 한 장), `vendor/tiptap-2.27.3.js`(편집기 부품 묶음), `design-styles.css`(코이데 디자인 스타일, `app/`과 같은 파일), `demo-data.js`(내 기록의 예시 자료), `questions-data.js`(오늘의 질문 409개와 이번 주의 질문 52개, 스크립트가 만든다), `img/q/`(오늘의 질문 그림 409개, 줄인 webp), `img/w/`(이번 주의 질문 정물 그림 52개, 줄인 webp), `tools/make-data.py`(위 자료와 그림을 만드는 스크립트).
- **열어 보는 법:** 이 폴더에서 `python3 -m http.server`를 켜고 `http://localhost:8000/`을 열어요. 오른쪽 위 작은 톱니(시안 보기 설정)에서 날짜를 바꾸거나, 예시 기록을 채우거나, 처음부터 다시(기록도 지워져요) 볼 수 있어요.
- 이름과 내용은 모두 지어낸 예시예요. 오늘의 질문과 그림은 AI 초안이고 사람이 확인하기 전이에요.
- 포도나무: 무언가를 남긴 날(질문·발견 남기기, 오늘의 질문 품기, 탐구 노트 쓰기, 이번 주의 질문 다 펴 보기)이 머문 날이에요. 머문 날마다 잎이 하나 돋고 열흘마다 성령의 열매가 맺혀 90일이면 아홉 열매가 다 맺혀요. 기록 자리는 didako-note-vine(start·days·dew·seen)이고 잠긴 덩어리로 동기화돼요(합칠 때 start는 이른 날, 나머지는 합집합). 화면에 숫자는 쓰지 않아요. 그림은 img/vine/(원본은 art/vine/)이고, 내 기록 오른쪽 위 포도잎 아이콘에서 열어요. 오늘의 질문 맨 아래 한 줄에서 포도나무로 가요. 그날 처음 머물면 "오늘 잎 하나가 돋았어요"를, 열흘째 날에는 열매 장면(img/vine/stories)을 한 번 보여 줘요(VN.seen). 나의 배지에 성령의 열매 9칸·포도나무, 다음 단계 포도원·새 포도주의 흐린 칸이 있어요. 아직 받지 않은 포도나무 배지는 재촉하지 않아요.

- **편집기 부품은 Tiptap 2(ProseMirror 바탕)예요.** 새로 만들지 않고 검증된 부품을 써요(`Intent.md` 5절). 쓰는 것: starter-kit(문단, 굵게, 기울임, 취소선, 인용, 글머리·번호 목록, 구분선), underline, highlight(한 색), text-style, color(글자색 다섯), text-align, table·table-row·table-header·table-cell, details·details-summary·details-content(접는 섹션), placeholder. `@tiptap/pm`(ProseMirror의 state·view)은 줄 앞 `? `·`! ` 상자와 지금 표 칸 표시에만 써요(못 불러와도 편집기는 돌고 상자 모양만 빠져요).
- **번호는 모두 2.27.3으로 같게 고정했고, `note/vendor/tiptap-2.27.3.js` 한 파일로 묶어 두었어요**(ProseMirror가 한 벌만 들어가요, 약 340KB, gzip 약 104KB). 버전·들어 있는 부품·만든 방법·저작권(Tiptap © überdosis GbR, ProseMirror © Marijn Haverbeke and others, 모두 MIT)은 그 파일 맨 위 주석에 있고, 라이선스 전문은 `vendor/LICENSE-tiptap-prosemirror.txt`에 있어요. 노트 화면을 처음 열 때 불러오고(그 전에는 아무것도 받지 않아요), 불러오지 못하면 그 화면에만 "편집기를 불러오지 못했어요"가 보이고 앱의 다른 곳은 그대로 돌아요. 그 안의 [다시 해 보기]는 페이지를 새로 열어요. 쓴 글은 이미 저장되어 있어요.
- **다시 묶는 법**(저장소 밖 빈 폴더에서): `npm i --save-exact @tiptap/core@2.27.3 @tiptap/pm@2.27.3 @tiptap/starter-kit@2.27.3 @tiptap/extension-underline@2.27.3 @tiptap/extension-highlight@2.27.3 @tiptap/extension-text-style@2.27.3 @tiptap/extension-color@2.27.3 @tiptap/extension-text-align@2.27.3 @tiptap/extension-table@2.27.3 @tiptap/extension-table-row@2.27.3 @tiptap/extension-table-header@2.27.3 @tiptap/extension-table-cell@2.27.3 @tiptap/extension-details@2.27.3 @tiptap/extension-details-summary@2.27.3 @tiptap/extension-details-content@2.27.3 @tiptap/extension-placeholder@2.27.3 esbuild` 한 뒤, 위 부품을 다시 내보내는 `entry.js`(`export { Editor, Extension } from '@tiptap/core'` 같은 줄들, 쓰는 이름은 `index.html`의 module 스크립트가 꺼내 쓰는 것과 같아요)를 두고 `npx esbuild entry.js --bundle --format=esm --minify --legal-comments=none --outfile=tiptap-2.27.3.js`(맨 위 주석은 `--banner:js`로 붙여요. 부품 이름·버전·MIT·저작권 두 줄·만든 방법을 적어요)를 돌려 `note/vendor/`에 두어요(`LICENSE-tiptap-prosemirror.txt`도 함께). node_modules와 빌드 폴더는 저장소에 넣지 않아요.
- **글은 `n.free = { doc, touched }`에 두어요.** 단계별로 쓴 글(`steps`)과 따로 있고 섞거나 옮겨 붙이지 않아요. `doc`은 편집기 문서(JSON)이고, 저장값을 읽을 때 아는 마디와 표시만 받고 나머지(이미지, 링크, 모르는 마디, 스타일 글)는 버려요. 화면에는 편집기가 그리고 HTML 글을 그대로 넣지 않아요.
- **저장:** 고칠 때마다 0.5초 쉬었다가 저장해요. 줄 맨 앞 `? `은 새 질문으로, `! `는 이 질문의 길에 "알게 된 것"으로 들어가는데(단계별로 쓰기와 같은 규칙, 짝 찾기 창 없음) 이것은 [저장 ✓]을 누르거나 화면을 떠날 때 처리해요.
- **내보내기:** PDF(보이지 않는 틀에 인쇄용 글을 넣고 인쇄 창을 불러요. 글자가 글자로 들어가요), Markdown(표는 GFM 표, 접는 섹션은 HTML details), TXT, HTML(접힌 섹션은 펼쳐서), 마크다운 복사예요. 맨 위에 질문·시작한 날·이 노트의 말씀, 맨 아래에 앱 이름이 있어요. 파일 이름은 "디다코 노트 - {질문 앞 20자}"예요. 모두 이 기기 안에서 만들고 서버로 보내지 않아요. 더보기의 "내 기록 내려받기"는 아직 "다음 단계에서 열려요"예요.
- **화면 꺼짐 방지:** 하나씩 쓰기와 자유롭게 쓰기 화면이 열려 있는 동안 Wake Lock으로 화면이 꺼지지 않게 해요(지원하지 않는 브라우저에서는 조용히 넘어가요).

## 오늘의 질문 409개와 이번 주의 질문 52개

- **오늘의 질문 409개**는 `docs/today-questions/`의 AI 초안이에요. 앱이 날짜마다 부활절을 계산해서(그레고리력) 대림절·성탄절기·주현절·사순절·부활절기·성령강림 후 절기 가운데 어디 며칠째인지 보고, 그 묶음에서 질문을 꺼내요. 고정 자리(대림절 첫 주일, 성탄절, 새해, 종려주일, 성금요일, 부활절, 승천일, 성령강림절, 삼위일체주일, 마지막 날들), 해마다 달라지는 길이(짧은 해에는 가운데를 건너뛰어요), 특별한 날(맥추감사주일, 종교개혁주일, 추수감사주일)은 `docs/today-questions/README.md`의 규칙 그대로예요.
